> presence and business-management platform to local service businesses (HVAC, plumbing,

## API status — read this before attempting an integration

GoSite markets a developer program but does NOT publish a machine-readable contract.
As probed on 2026-08-22:

- There is no public OpenAPI, Swagger, GraphQL SDL, AsyncAPI, Protobuf or WSDL document
  at any GoSite host.
- API access is approval-gated: create a GoSite customer account, submit a
  request-access form explaining your use case, and an API key is issued on approval.
- The Swagger reference the developer portal links to,
  https://api.developers.gosite.com/docs/, returns HTTP 502 Bad Gateway on every path.
- https://api.gosite.com/ is live but returns HTTP 401 with a JSON error envelope on
  every anonymous request.
- No rate limits, error catalog, scopes, webhooks, SDKs, CLI, sandbox or changelog are
  published.
- No MCP server, no A2A agent card, and no /.well-known documents are served.

An agent cannot integrate with GoSite from public information alone. Contact GoSite to
request access.
